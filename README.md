# 画里山城 · 版画除妖记

> 2026 首届重庆市小游戏创新创业大赛 · 「渝你同行」特色赛道参赛作品

一款通过战斗修复山城画卷的横版动作小游戏。綦江老版画师墨爷的木版里渗出了「浊墨」，吞掉了《山城百景图》的颜色。你作为守画人走进画里，用蜀绣飞针、铜梁龙舞、荣昌折扇打散浊墨，一幅一幅把颜色找回来。

**▶ 在线试玩：<https://lilkylin6-svg.github.io/hualishancheng/>**

电脑用浏览器直接打开；手机请横屏，触屏时会自动出现虚拟按键。

## 玩法亮点

- **修画即得：** 每清完一个区域，画面从灰色复色，同时还给玩家一样有用的东西：补给、石阶、照亮暗巷的龙灯、通往戏台的帷幕。
- **三把非遗武器：**
  - 蜀绣飞针：远程连发。
  - 铜梁龙舞：龙绕身，护住前后。
  - 荣昌折扇：扇风，把敌人扇飞、打断出招。
- **三位守画人：** 幺妹（蜀绣绣娘）、棒棒（山城挑夫）、变脸匠（川剧艺人），各有不同特性。
- **Boss 张不管：** 被浊墨迷住的川剧丑角，要识破他的「假投降」，还能用折扇把他的飞扇扇回去。
- **剧情：** 序章、关内方言对话、尾声和章节地图。第一章完整可玩，后三章在规划中。

## 目录

| 路径 | 内容 |
|---|---|
| `prototype/` | **游戏本体**（纯 HTML5 Canvas，无依赖）。部署的就是这个文件夹，详细说明见 [prototype/README.md](prototype/README.md) |
| `assets/` | Codex 生成的原始美术素材（PNG），以及 `素材来源登记.csv`（AIGC 素材登记，提交比赛必须保留） |
| `剧情大纲.md` | 世界观、人物、章节结构、第一章完整剧本 |

| `画里山城_游戏设计方案_v4.0_参赛优化版.docx` | 设计方案（v4.0，**还没同步**武器重做、角色、新画风、剧情这些后来的改动） |
| `.github/workflows/pages.yml` | 推送到 `main` 后自动部署到 GitHub Pages |

## 本地运行

- **最简单：** 双击 `prototype/index.html`。
- **用本地服务器**（加载更接近线上环境）：

```bash
python -m http.server 8765 --directory prototype
```

然后打开 <http://localhost:8765>。自动测试页：<http://localhost:8765/test.html>。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动把 `prototype/` 发布到 GitHub Pages，一两分钟后线上就是新版本。进度可以在仓库的 **Actions** 页面看。

## 更新美术素材

1. 用 AI 工具重新生成某张图，文件名不变，覆盖到 `assets/`。
2. 运行处理脚本（需要先 `pip install pillow`）：

```bash
python prototype/tools/build_assets.py
```

3. 提交并推送，线上自动更新。

## 素材与原创声明

- 墨爷、张不管、「万年台」等人物和地名均为原创虚构，不对应真实人物或剧目。
- 部分美术素材使用 AI 工具（Codex 内置图像生成）生成，已在 `assets/素材来源登记.csv` 中逐一登记来源，并经人工筛选。
- 游戏代码、剧情、数值设计均为团队原创。
