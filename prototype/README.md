# 画里山城 · 游戏本体 v0.6

第一章完整可玩，包括修画即得、三把武器、三位可选守画人、两阶段张不管、战区重试、辅助拓印、序章与尾声剧情。美术已换成 AI 生成的正式素材，还没有配音和音乐。

**在线试玩：<https://lilkylin6-svg.github.io/hualishancheng/>**（推送到 `main` 后自动更新）

> **已知问题：** 部分设备上明显卡顿。帧率偏低时，游戏会自动把画布分辨率降到 1 倍、再降到 0.8 倍。性能优化是下一步的待办。

## 怎么玩

- **在线：** 打开上面的链接。手机请横屏，触屏时会自动显示虚拟按键。
- **本地：** 双击 `index.html`，用浏览器打开就能玩，不需要安装任何东西。

开局先选一位守画人：键盘用 ← → 或 1/2/3 选择，按 J 或空格开始；手机点卡片选择，再点一次开始。

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | A / D 或 ← → | ◀ ▶ |
| 跳跃 | 空格（W、↑ 也可以） | 跳 |
| 普攻（可按住连发） | J | 攻 |
| 特色技 | K | 技 |
| 切换武器 | 1 / 2 / 3，Tab 循环 | 针 / 龙 / 扇 |
| 暂停 | Esc | Ⅱ |

结算界面按 **C** 复制本局试玩数据（JSON），按 **J** 用同一角色再玩，按 **B** 回到选角界面。

## 美术素材（v0.6）

Codex 生成的原始素材在项目根目录的 `assets/` 里（PNG，约 70MB，还有 `素材来源登记.csv`）。游戏用的是处理过的版本，放在 `prototype/assets/` 里（WebP，约 3.7MB）。

**换图流程：**
1. 用 Codex 重新生成某张图，文件名不变，覆盖到根目录的 `assets/` 里。
2. 在 `prototype` 目录下运行 `python tools/build_assets.py`（需要先装 Pillow：`pip install pillow`）。
3. 刷新游戏。

**处理脚本会做这几件事：**
- 缩放到游戏里的显示尺寸、裁掉透明的空白边、转成 WebP。
- 从三视图里切出侧面像，并算出人物脚底的位置。
- 生成素材清单 `assets/index.js`。

**素材在游戏里怎么用：**
- **守画人：** 上半身用三视图的侧面像，腿用拆件做摆腿动画；变脸匠穿长袍，整体滑行。头、躯干、手臂拆件暂时没用上，因为单独拼起来比例对不上。
- **张不管：** 用侧面像，矮子步冲撞时压扁，出招时叠加展开的折扇。
- **其他：** 背景、地面、标志物、小怪、特效、道具、界面、剧情插图都已接入。宣传图不进游戏。
- **兜底：** 缺哪张图，就用代码画哪部分，所以加载过程中游戏照样能玩。网址加 `?noimg` 可以只看代码画面做对比。

**性能：**
- 加载器最多同时加载 6 张，失败自动重试 3 次。背景和第一区的图排在前面，最先加载。
- 帧率连续偏低时会自动降低画布分辨率（1.25 → 1 → 0.8 倍）；网址加 `?dpr=1.25` 可以锁定画质，不自动降档。

**已知问题：**
- 序章最后一张插图里的守画人是幺妹。选棒棒或变脸匠时，那一格会额外叠上他们自己的立绘。最好让 Codex 给这两位各补一张。
- 还需要在真手机上测一次帧率。

## 剧情（v0.5）

剧情总纲在项目根目录的 `剧情大纲.md`，游戏里的台词全部在 `story.js`，改台词只改这个文件。

- **序章（8 句）：** 墨爷的画室，雨夜。木版裂开，浊墨爬上墙上的《山城百景图》，画慢慢褪色，墨爷倒下，守画人登场。第 7 句按所选角色说不同的话。
- **关内对话（8 处）：** 在进入画中、各区域复色、拿到龙舞和折扇、帷幕拉开时出现，以字幕显示并带说话人。
- **张不管（5 句）：** 登场、转二阶段、被拆穿、被自己的扇子打中、被击败。
- **尾声（5 句）：** 谢幕，然后展开《山城百景图》章节地图。前两章已完成，后三章锁着，标「敬请期待」。
- **操作：** J、空格或点击推进，按 Esc 跳过整段；同一次打开游戏只播一次序章。网址加 `?nostory` 可以完全跳过剧情。

## 画风：「发光山城」（v0.4 已铺满整关）

默认打开就是新画风，按 **V** 可以和灰盒来回切换，在网址后面加 `?art=0` 则直接用灰盒打开。新画风写在 `art.js` 里，只负责画面，不改游戏逻辑。

**各区域的标志场景：**

| 区域 | 场景 |
|---|---|
| ① 羊肉摊 | 红布篷汤摊、三盏灯笼；复色后锅里冒热气 |
| ② 青石梯坎 | 身后一道爬上山的大梯坎和路灯；一棵黄葛树（重庆市树），有气根 |
| ③ 龙灯街 | 一串红灯笼，加一条悬在街上、会起伏游动的龙灯；复色后整条龙亮成金色 |
| ④ 戏台前场 | 卖荣昌折扇的摊子，三面迎风的彩旗；出口是红色帷幕 |
| ⑤ 戏台 | 万年台：飞檐屋顶、红柱、屏风、大红灯笼；结尾时前景是举着灯笼欢呼的看戏人群 |

**其他画面：**
- **张不管：** 川剧丑角剪影，戴丑角帽、帽翅会动，鼻梁上有发亮的白"豆腐块"。所有预警（冲撞红线、倒计时、「冲！」、「投降！」、破绽金光）都和灰盒保持一致。
- **投射物与道具：** 都做成发光的样子；飞扇的地面箭头和「回！」提示保留。
- **标题与选角：** 背景是整幅山城缓缓平移，选角卡片上是角色的剪影立绘。

**性能：**
- 画布分辨率默认最多 1.25 倍，网址加 `?dpr=2` 可以手动调高画质。
- 实测帧率：电脑 60 帧；无显卡加速的手机模拟环境 35～50 帧。**还需要在真手机上测。**
- 如果真机卡顿，可以在浏览器控制台设置 `window.__artSkip = ['layers','desat']` 等，临时关掉某些效果来定位问题。

- **画面构成：** 暮色天空和光柱、三层远山、江面波光、两层吊脚楼（窗户会亮灯）、江雾、近景雾、前景枝叶和草丛、漂浮的光点、暗角。
- **失色与复色：**
  - 没修复的区域整体去色、压暗。
  - 清完怪后，光波从主角脚下向两边推开，颜色、窗灯、灯笼依次亮起，同时飞出彩色光屑。
  - 羊肉摊复色后，锅里会冒热气。
- **角色：** 守画人是深色剪影，带轮廓光、发光的眼睛和会飘动的围巾；秧鸡妖和谷穗怪是墨色剪影，眼睛发红光。
- **素材来源：** 全部用代码绘制，没有使用任何外部图片，权属清楚。

## 调试参数

在网址后面加：

- `?area=5`：直接从第 5 区开始（1～5 都可以，前面的区域自动算作已修复）。
- `?char=3`：默认选中第 3 位角色（1 幺妹、2 棒棒、3 变脸匠）。
- `?god`：无敌。
- `?debug` 或按 **F1**：显示碰撞框、敌人状态和帧率。

例如：`index.html?area=5&char=2&god`

## 文件

| 文件 | 内容 |
|---|---|
| `story.js` | 第一章的全部台词：序章、关内对话、张不管、尾声、章节地图。 |
| `art.js` | 「发光山城」画风，只负责画面。 |
| `config.js` | **全部可调数值和关卡布局**：武器、角色、敌人、Boss、5 个区域的位置、波次和复色返还。试玩后只改这个文件。 |
| `game.js` | 游戏逻辑与绘制。流程逻辑（`step`）和画面（`render`）分开，演出出问题也不会卡住通关。 |
| `test.html` / `test.js` | 自动回归测试，打开即运行。用脚本玩家跑完整关，并检查重试、辅助拓印、暂停、三把武器、三位角色、Boss 各阶段、剧情流程等 76 项规则。 |

每次改完数值或代码，打开一次 `test.html`，确认全部通过再给别人试玩。

## 三把武器（v0.2 重做）

| 武器 | 普攻 J | 特色技 K | 擅长的场面 |
|---|---|---|---|
| 蜀绣飞针 | 三连发，射程 7，遇到第一个敌人就停。拿到龙舞后每 6 轮要换线 1.5 秒 | 晕针穿刺：贯穿一排并定身 | 打远处的敌人 |
| 铜梁龙舞 | **龙绕身**：小龙绕身一圈（半径 2.6），前后都打并向外弹开；绕身期间挡下谷粒和飞扇 | **游龙**：向前穿身冲刺 4 单位，途中无敌，路过的敌人各吃一次伤害 | 被包围、要穿过敌人 |
| 荣昌折扇 | **扇风**：向前扇一阵风（3.5 单位），把小怪扇飞 3 单位，打断冲锋和抛射，吹散谷粒 | 扇面迷阵：减速区，切换武器后仍然存在 | 拉开距离、打断对手 |

**Boss 战里的「以扇破扇」：**
- 折扇扇风能把张不管的飞扇扇回去，他被自己的扇子打中，会晕 2.2 秒。
- 折扇扇中正在假投降的张不管，就能当场拆穿，取消突袭，并露出 2.6 秒破绽。
- 龙绕身只能挡下飞扇，不会把它扇回去。

## 三位守画人（v0.2 新增）

| 角色 | 身份 | 特性 |
|---|---|---|
| 幺妹 | 蜀绣绣娘 | 飞针专精：线量 8、换线 1 秒、穿刺冷却 −1 秒；生命 90 |
| 棒棒 | 山城挑夫 | 生命 130，挨打几乎不踉跄，龙舞伤害 +25%；移动速度 ×0.9 |
| 变脸匠 | 川剧艺人 | 一换武器就「变脸」：0.4 秒无敌，下一击伤害 +50%；换武器几乎没有间隔 |

**美术提醒：** 三位角色在灰盒里只是换了头部、颜色和道具。正式美术建议也照这个思路：共用一套身体动作，只换发髻 / 扁担 / 脸谱和服装颜色，否则每个角色都要单独画一整套动作，赶不上 12 月的截止时间。

## 其他已实现

- 5 个修复区域，以及各自的复色返还：羊肉摊开张后出现补给、石阶成形、龙灯照亮暗巷、戏台前场拉开帷幕、戏台全景谢幕。
- 两类小怪：秧鸡妖有冲锋路线预警；谷穗怪抛谷粒，有落点预警。
- 张不管：
  - 一阶段：回旋扇、矮子步冲撞。
  - 二阶段：加入假投降。
  - 出招中只受一半伤害，破绽期间吃全额伤害。
  - 飞扇折返前会停顿并标出「回！」，冲撞前有倒计时条，开冲瞬间标出「冲！」。
- 「再拓一次」重试：同一战区连续失败 2 次后，询问是否开启辅助拓印。
- 羊肉补给（满血时不消耗）、5 条方言字幕、暂停（切出页面也会自动暂停）、结算与试玩数据统计。
- 键盘和触屏两套操作；手机竖屏时提示横过来玩。

## 试玩记录与改动

| 轮次 | 关键数据 | 发现 | 改动 |
|---|---|---|---|
| 第 1 次 | 打不赢 Boss | 冲撞时张不管的判定高 2.4，比跳跃高度 2.2 还高，根本跳不过去 | 矮子步压低身体；假投降突袭缩短到 6 单位；二阶段送羊肉；每招第一次出现时给提示 |
| 第 2 次 | 通关，500 秒；Boss 战死 7 次，被飞扇命中 32 次；普攻比例 408 : 23 : 3 | 飞扇回程没有提示；冲撞起跳时机不明确；几乎只用飞针 | 飞扇折返前停顿并标出「回！」；冲撞前加倒计时和「冲！」；飞针加换线；加入「以扇破扇」 |
| 第 3 次 | 通关，242 秒；Boss 战 89.5 秒，0 次死亡；普攻比例 150 : 16 : 0，扫回和拆穿都是 0 次 | Boss 战调好了；但龙舞要贴脸、折扇伤害低，玩家宁可等换线也不切武器 | **v0.2：** 折扇改成扇风，龙舞改成龙绕身并新增游龙冲刺；加入三位可选守画人 |

## 仍需真人确认

- **龙灯街的摊棚可能变成安全点。** 站在摊棚上，秧鸡妖冲不到玩家。现在的处理是：玩家在高处时，秧鸡妖会退到 3 单位外等着。
- **暗巷目前只是视觉效果。** 玩家必须先修好龙灯街才能进入暗巷，所以"照亮后看清敌人"还没有真正影响玩法。
